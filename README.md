Python Weather Application 🌦️

A simple Python project that fetches current weather information for a city using the Open-Meteo API.

Features:

*Search weather by city name

*Display temperature in Celsius

*Display relative humidity

*Display wind speed

*Handle invalid city names

*Handle API and connection errors

Technologies Used:

*Python

*Requests library

*Open-Meteo Geocoding API

*Open-Meteo Weather API

Requirements:

*Python 3 and the requests library.

*Install the library using:

*python -m pip install requests

How to Run:

*Clone or download this repository.

*Open a terminal in the project folder.

Run:

python Weather_App.py

Enter a city name when prompted.

Example Output:

===== CURRENT WEATHER =====
City: Kurnool
Temperature: 30.6 °C
Humidity: 54 %
Wind Speed: 8.3 km/h

Weather values change depending on the location and time.

Weather Data

Weather information is provided by Open-Meteo.
